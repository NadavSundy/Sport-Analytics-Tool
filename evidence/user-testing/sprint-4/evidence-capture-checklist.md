# Sprint 4 evidence capture checklist

## Before the session

- [ ] Anonymous ID checked against P01-P14 and any concurrent allocations; participant is not a workflow implementer/designer.
- [ ] Purpose explained; recording consent explicitly recorded if recording, otherwise no recording retained.
- [ ] Actual date/time, browser/version/device, URL, frontend/API/worker build or honest unavailable limitation recorded.
- [ ] Account label/authoritative role/scope checked; no credentials captured.
- [ ] Exact selected tasks and canonical wording ready; facilitator guide hidden.
- [ ] Scenario state, input version/checksum, safe target and reset method verified; fixture 5 never a write target.

## During each task

- [ ] Record attempted/unattempted separately, with blocker/reason for omissions.
- [ ] Record independent Success / Partial / Failure only for actual attempts.
- [ ] Retain observed actions, hesitations, errors, requested and given assistance, positive observations.
- [ ] Mark participant comments as verbatim quotes or paraphrases; do not turn paraphrases into quotes.
- [ ] Capture the relevant screen/state only; name it with real date, anonymous ID, role and Task ID.
- [ ] Record environmental interruption and restart separately; preserve any earlier attempted outcome.
- [ ] Ask all six canonical post-test questions and retain actual responses or explicitly missing answers.

## Before sending/committing

- [ ] Source notes, session interpretation, analysis and retest are distinguishable.
- [ ] Remove surnames, personal email, OAuth account selectors, passwords, tokens, keys and unrelated information from notes/screenshots/metadata.
- [ ] Facilitator confirms factual interpretation and proposed severity/decision; ambiguities remain pending.
- [ ] Session-local F01 etc. links to Task ID; cross-session identity includes participant/session path.
- [ ] Each meaningful finding has final state and reason; accepted S1/S2 changes have human retest evidence before close-out.
- [ ] Links, file names and inputs match real retained evidence; non-versioned inputs have SHA-256.
- [ ] Stage only explicit reviewed files; no generated reports, secrets, raw personal records or unrelated changes.
