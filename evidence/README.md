# Project evidence

Store genuine evidence here so project claims can be traced to records.

- `stakeholder-meetings/`: agendas, minutes, feedback, and decisions
- `sprints/`: planning, weekly summaries, reviews, and retrospectives
- `decisions/`: architecture decision records
- `user-testing/`: plans, consent-aware notes, results, evaluation, and changes
- `ai/`: AI usage register and per-team-member transcript records

Do not invent meetings, attendance, decisions, results, feedback, or contributions. Use filenames with ISO dates and link relevant Gitea issues and Pull Requests.
