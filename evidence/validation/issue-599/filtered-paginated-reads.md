- **unfiltered fixture list, first page**: Baseline for the rows below; the same request the #289 harness measures.
- **fixture list filtered by competition**: Worst case for this corpus: every one of the 300 fixtures belongs to the single generated competition, so the filter removes nothing and the predicate is pure overhead.
- **fixture list filtered by start-date range**: Genuinely selective: the generated dates span about eleven months and this range selects roughly one month of them.
- **fixture list, last page of 6**: Deep cursor page. An offset-based cursor degrades with depth and a keyset cursor does not; page one cannot tell the two apart.
