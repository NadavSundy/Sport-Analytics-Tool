# Azure deployment investigation

Azure is the team’s preferred deployment platform, but no exact service choice is approved by this scaffold.

Before Milestone 1, prototype independent deployment of the frontend, backend health endpoint, database connection, and MkDocs site. Record public URLs, exact commands, secret handling, CORS/HTTPS behaviour, logs, health monitoring, rollback steps, and cost or student-credit impact.

Create an architecture decision record after comparing candidate services for static frontend hosting, managed or containerised Node.js hosting, database hosting, static documentation hosting, and secret management.
