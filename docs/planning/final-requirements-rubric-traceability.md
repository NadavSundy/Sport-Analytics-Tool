## Status key and marker route

| Status              | Meaning                                                                                                                           |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **Implemented**     | Retained implementation exists with representative automated, integration, deployment or user-facing evidence linked below.       |
| **Partial**         | A meaningful portion exists, but a stated limit, unverified final-release step or remaining capability prevents a complete claim. |
| **Not implemented** | The final product does not claim this capability.                                                                                 |
| **Not applicable**  | The capability is outside the chosen final product scope; the reason is recorded rather than silently treating it as complete.    |
