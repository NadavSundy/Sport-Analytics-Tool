# Sprint Evidence

This page indexes the Sprint methodology trail so each milestone can be followed
chronologically. It links to the authoritative records under
[`evidence/sprints/`](https://sdp.ms.wits.ac.za/git-push-pray/Sport-Analytics-Tool/src/branch/main/evidence/sprints)
rather than duplicating them.

A new Sprint folder is created under `evidence/sprints/sprint-<n>/` for each milestone, following
the structure described in the
[Sprint evidence README](https://sdp.ms.wits.ac.za/git-push-pray/Sport-Analytics-Tool/src/branch/main/evidence/sprints/README.md).
Future Sprint evidence should be added as a new dated entry under the relevant Sprint's heading
below, keeping this page as the ongoing navigation point.
